# 🐶 Pream
반려동물 용품 중고 거래 플랫폼

## 프로젝트 정보 🚀
반려동물 용품은 높은 가격과 짧은 사용 주기를 가지고 있어, 많은 소비자들이 중고 거래를 통해 경제적 부담을 줄이고자 합니다.

중고 거래를 안전하고 신뢰성 있게 진행할 수 있는 서비스를 제공하는 것을 목표

> **프론트엔드**<br/>
> TypeScript / React / emotion / zustand / react-query / pnpm<br/>
> **백엔드**<br/>
> TypeScript / NestJS / PostgreSQL / Prisma

## 핵심 기능
- 반려동물 용폼들을 목록으로 조회하고, 상세한 상품 정보들을 조회할 수 있습니다.
- 카테고리 별로 상품을 조회할 수 있습니다.
- 자신의 물건을 등록하여 판매할 수 있습니다.
- 다른 사람이 등록한 물건을 구매할 수 있습니다.
- 구매 시, PG결제 시스템을 적용하여 간편 결제를 할 수 있습니다.
- 판매/구매한 상품 내역을 조회/취소할 수 있습니다.

- 카카오 계정을 이용한 소셜 로그인을 사용할 수 있습니다.
- 사용자와 반려동물의 프로필을 작성하고 수정, 삭제할 수 있습니다.

## 로컬 실행 방법

- 본 프로젝트에서는 20.17.0 버전을 사용하므로 nvm을 이용하여 노드 버전을 맞춰 주세요!

  ```bash
  node --version
  ```

  - 만약 버전이 다르다면 `nvm`을 이용하여 node 버전을 변경합니다.

- 아래 코드는 클론 후 최초 1번만 실행합니다.
  ```bash
  npm install -g pnpm@9.9.0
  pnpm install
  ```
- 서버를 실행합니다.
  ```bash
  pnpm dev
  ```
